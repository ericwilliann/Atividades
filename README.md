# 🧠 Atividades de Aprendizado em HTML, CSS e JavaScript

Repositório criado para reunir minhas **atividades iniciais de aprendizado em desenvolvimento web**, com foco em estrutura de páginas, estilização visual e introdução à lógica de programação.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estruturação das páginas  
- **CSS3** — Estilização e layout  
- **JavaScript** — Lógica, interatividade e manipulação do DOM  

---

## 📂 Conteúdo do Repositório

- **Atividade CRUD Alunos** — Exercício de cadastro, listagem e exclusão de dados em memória  
- **Atividade LNG PRG** — Prática envolvendo lógica e manipulação de variáveis em JavaScript  
- **Atividade Form** — Exercício de criação e validação de formulários com HTML e CSS  

---

## 🎯 Objetivo

O objetivo deste repositório é **praticar conceitos fundamentais** do desenvolvimento web front-end, aprimorando:
- Estrutura semântica em HTML  
- Uso eficiente de seletores e estilos em CSS  
- Criação de scripts JavaScript para adicionar comportamento dinâmico às páginas
